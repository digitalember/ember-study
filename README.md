# EMBER — Blind Transcript Rating Study

External evaluation study for the EMBER research project. Participants rate text generated by an automated pattern-detection system across three tasks:

1. **Context matching** — determine whether a message was generated from a given set of input data
2. **Quality rating** — rate messages on three scales, stored as `grounding`, `continuity` and `specificity`
3. **Topic counting** — identify distinct knowledge domains referenced in generated text

Tasks 1 and 2 present the context pack and the generated message side by side, with the rating
controls spanning both panels underneath. Participant-facing wording for the Task 2 scales is
defined in `T2_SCALES` and the explanatory tooltips in `TIPS`, both near the top of the script
block — the stored response keys are deliberately decoupled from the displayed labels so the
wording can be revised without breaking analysis.
