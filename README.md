# EMBER — Blind Transcript Rating Study

External evaluation study for the EMBER research project. Participants rate text generated by an automated pattern-detection system across three tasks:

1. **Context matching** — determine whether a message was generated from a given set of input data
2. **Quality rating** — rate messages on contextual grounding, thematic continuity, and non-genericness
3. **Topic counting** — identify distinct knowledge domains referenced in generated text
