AI System Evaluation

Thank you for participating. In this study you will evaluate text generated by an automated messaging system. The system monitors data from a pattern-detection layer to periodically generate a message to send to its operator, write a log entry, or take no action.

You will complete three short tasks:

  1. Context matching (40 items) — decide whether a message was generated from a given set of input data
  2. Quality rating (30 items) — rate messages on three scales
  3. Topic counting (10 items) — count distinct knowledge domains in a response

Estimated time: 40–50 minutes. Please read each item carefully. There are no trick questions.
